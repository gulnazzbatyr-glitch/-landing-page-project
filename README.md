# Nova Studio — Landing Page

A responsive landing page for a fictional digital agency, built as a frontend internship project.

## Features

- Responsive layout for mobile, tablet, and desktop
- Sticky header and mobile hamburger navigation
- Hero section with call-to-action buttons
- About section and three service cards
- Three sample testimonials
- Contact section and footer
- Smooth anchor scrolling and scroll-triggered animations
- Reduced-motion accessibility support

## Tech stack

- HTML5
- CSS3 (Grid, Flexbox, media queries, transitions)
- Vanilla JavaScript (DOM events, IntersectionObserver)

## Run locally

Open `index.html` in a browser. No build step or dependencies are required. An internet connection is useful to load the Google Fonts used in the design.

## Deploy

1. Create a public GitHub repository named `landing-page-project`.
2. Upload `index.html`, `style.css`, `script.js`, and this README.
3. In repository Settings → Pages, choose **Deploy from a branch**, branch **main**, folder **/(root)**, and save.
4. Wait for the published URL to appear. Test it on mobile and desktop.
5. Submit the GitHub repository link as **Submission URL** and the published link as **Live / Demo URL**.

## Notes

Nova Studio is fictional. All company statistics, client names, and testimonials are sample content for demonstration purposes. The `.example` email address is a placeholder, not a working business inbox; replace it before using the project for a real company.
